# Démarrage rapide

```bash
git clone https://github.com/josoavj/PlanificatorFinal.git
cd PlanificatorFinal/planificator
flutter pub get
flutter analyze
flutter test
```

Configurez ensuite MySQL depuis l'écran de premier lancement et créez le premier
compte administrateur. Pour contribuer, utilisez une branche dédiée et ajoutez un
test à toute nouvelle règle métier.
