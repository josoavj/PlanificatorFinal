Installer Planificator

1. Préparer MySQL

Installez MySQL 8 ou MariaDB sur votre machine ou votre réseau. Utilisez un compte dédié et limitez l'accès au port 3306.

2. Installer l'application

Téléchargez l'archive correspondant à Windows ou Linux depuis GitHub Releases. Décompressez-la dans un dossier dédié.

3. Configurer la base

Au premier lancement, indiquez l'hôte, le port, la base, l'utilisateur et le mot de passe. Le schéma et les migrations sont vérifiés automatiquement.
