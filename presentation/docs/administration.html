Administrer les comptes

Les privilèges portent sur les actions sensibles de l’application et doivent être réservés aux personnes responsables.

Créer le premier administrateur

Après connexion à une base sans compte, Planificator affiche le formulaire initial. Ce parcours crée un compte administrateur et génère un code de récupération. Enregistrez-le dans un gestionnaire sécurisé ou un emplacement hors ligne contrôlé ; il ne peut pas être récupéré en clair depuis la base.

Une fois le premier compte créé, l’inscription publique ne propose que le rôle utilisateur. Le rôle administrateur n’est attribué que depuis l’écran de gestion des comptes par un administrateur existant.

Gérer un compte

  1. Ouvrez Paramètres → Administration → Gestion des comptes.
  2. Sélectionnez un autre compte pour afficher son rôle actuel.
  3. Choisissez « Administrateur » ou « Utilisateur », puis « Modifier le rôle ».
  4. Confirmez avec le mot de passe de l’administrateur connecté.
  5. Pour une suppression, choisissez « Supprimer le compte » et confirmez à nouveau avec le mot de passe.

Un administrateur ne peut pas modifier ni supprimer son propre compte depuis cette liste. Il peut utiliser les fonctions de profil ou de suppression de son propre compte accessibles dans les paramètres.

Règles de conservation : la base doit garder au moins un administrateur et accepte au plus trois administrateurs. Le schéma et l’application appliquent ces limites.

Actions réservées aux administrateurs

  • Gérer les rôles et supprimer d’autres comptes.
  • Modifier la connexion à la base de données, après revalidation du mot de passe.
  • Effectuer les actions financières réservées, notamment les changements de prix.
  • Accéder aux fonctions de sécurité et d’exploitation prévues par l’application.

Récupération du compte administrateur

Depuis l’écran de récupération, saisissez l’adresse e-mail du compte, le code de récupération initial et un nouveau mot de passe conforme aux règles de complexité. Après utilisation, le code est invalidé ; stockez le nouveau mot de passe dans un gestionnaire sécurisé. Si le code a été perdu, un administrateur de base de données devra effectuer une procédure de récupération contrôlée.

Limites opérationnelles

Les règles d’accès sont appliquées par l’application et les triggers du schéma SQL. Comme les postes se connectent directement à MySQL, toute personne possédant des identifiants SQL suffisamment privilégiés peut aussi effectuer des modifications en dehors de l’application. Restreignez donc le compte SQL, les hôtes autorisés et les droits d’administration du serveur.
