Analyse et tests automatisés

Le dépôt contient des tests ciblant les repositories, services, modèles, validateurs et règles métier.

Commandes courantes

flutter analyze
flutter test

L’analyse statique vérifie les erreurs et règles du code Dart. Les tests automatisés exécutent les cas définis sous test/. Leur présence ne remplace pas une validation manuelle de l’application avec une vraie base de test.

Modules de test présents

DossierPérimètre
ConfigurationPersistance et paramètres de connexion à la base.
ModèlesConversion et comportement des objets métier.
RepositoriesAuthentification, clients, contrats, factures, planning et remarques.
ServicesConnexion MySQL et cache de requêtes.
UtilitairesDates, exports, montants et validateurs.

Base de données simulée

Les tests de repositories utilisent un mock de DatabaseService pour simuler les requêtes, transactions et réponses SQL sans nécessiter une base de production.

Ne testez pas les changements sur une base contenant des données réelles. Le script initial de schéma supprime et recrée la base. Pour tester les parcours, créez une base séparée dédiée au développement.
